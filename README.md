# 📋 Trello Clone — Vanilla JS

An interactive, responsive task management board inspired by Trello, built entirely from scratch using **pure HTML5, CSS3, and Vanilla JavaScript** — with **zero frameworks or third-party libraries**.

---

## 🚀 About the Project

This project reproduces the core Kanban workflow of Trello in a lightweight, fast, and dependency-free web application. It was developed to practice DOM manipulation, drag-and-drop interactions, dynamic state management, and modern UI/UX principles using plain web standards.

---

## ✨ Features

- 📌 **Dynamic Lists & Cards:** Create, rename, and delete custom boards/columns and task cards.
- 🖐️ **Interactive Drag & Drop:** Easily reorder tasks or move them across different status columns.
- ✏️ **In-line Editing:** Quickly update card details, titles, and descriptions.
- 💾 **Local Storage Persistence:** Tasks and lists are automatically saved in the browser, preserving data on page refresh.
- 📱 **Responsive UI:** Clean, modern layout designed to adapt smoothly across desktop and mobile browsers.
- ⚡ **Zero Dependencies:** Pure client-side application with zero external npm packages or build tools.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic markup and structure.
- **CSS3:** Custom styles, Flexbox, CSS Grid, animations, and custom properties (CSS variables).
- **JavaScript (Vanilla ES6+):** Event handling, HTML5 Drag and Drop API, DOM manipulation, and `localStorage` integration.
